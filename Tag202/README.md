Notizen zum Buch [Buch 1](../Buch1.md).

Ab Seite 239:
* Zusammenfassung des BB84-Protokolls
  - Alice unterwirft die Qubits einer zufälligen Bitfolge jeweils einer zufällig ausgewählten $X$ oder $Z$ Operation
  - Bob bekommt die modifizierten Qubits
  - Bob unterwirft die Qubits ebenfalls einer jeweils zufälligen $X$ oder $Z$ Operation
  - Bob informiert Alice darüber
  - Alice informiert Bob, an welchen Stellen haben sie die gleiche Wahl getroffen
  - An diesen Stellen gültigen Bitwerte bilden einen gemeinsamen Schlüssel
